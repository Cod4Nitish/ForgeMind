# ForgeMind

ForgeMind is an AI Software Engineer agent built for the Build with Swytchcode — Gurgaon Edition.

It reasons about development work and coordinates actions across GitHub, Jira, and Slack using LangGraph.js, Claude/Anthropic, and Swytchcode.
